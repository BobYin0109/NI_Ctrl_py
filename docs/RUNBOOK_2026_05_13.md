# Runbook 2026-05-13

This is the hardware-tested configuration for the PI E-727.3CD, NI PCIe-6353,
SCB-68A, and HCImageLive setup.

## Hardware Mapping

| Function | SCB-68A terminal | Python line |
| --- | --- | --- |
| CMOS EXT. TRIG signal | 40 | `Dev1/port2/line5` |
| CMOS EXT. TRIG ground | 7 / D GND | n/a |
| CMOS TIMING signal | 41 | `Dev1/port1/line4` |
| CMOS TIMING ground | 9 / D GND | n/a |

PI controller:

- Controller: `E-727`
- Connection: USB
- USB serial: `0121031417`
- Controller ID observed: `E-727.3CD, 121031417, 01.028`

Close PI MikroMove before running Python.

## HCImageLive Settings

Use `configs/hcimagelive_mono_external_trigger.json` as the captured camera-side
configuration record.

Important settings:

- Capture preset: `Mono: 1 Channel`
- Capture mode: `External Edge Trigger`
- Trigger edge: `Pos`
- Speed: `2`
- Sequence type: `Time Lapse`
- AutoSave: enabled
- File type: `TIFF`
- Destination: `to Disk`
- Control: `End Frame`

For the 49-51 um / 10 nm stack set `End Frame = 201`, choose a new empty
AutoSave folder, then click `Start`.

Disable Nikon Eclipse Ti2 auto focus lock before scanning.

## Proven Commands

Small 3-image test:

```powershell
.\.venv\Scripts\ni-ctrl.exe scan --config configs\small_test.json --confirm-hardware
```

11-image Z-stack test:

```powershell
.\.venv\Scripts\ni-ctrl.exe scan --config configs\z_stack_11_test.json --confirm-hardware
```

201-image 49-51 um / 10 nm Z-stack:

```powershell
.\.venv\Scripts\ni-ctrl.exe scan --config configs\z_stack_201_49_51_10nm.json --confirm-hardware
```

The 201-image stack maps as:

- `Image1_1.tif` -> `Z = 49.000 um`
- `Image1_101.tif` -> `Z = 50.000 um`
- `Image1_201.tif` -> `Z = 51.000 um`

The scan code returns the Z axis to `z_home_um` after every scan. The current
tested configs use `z_home_um = 50.00`.
